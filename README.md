# CF 避雷小本本

> 玩游戏最扫兴的从来不是输，是遇到那些**开局速抓、团战挂机、输了甩锅、赢了嘲讽**的人。
> 我受够了。
>
> 所以我把每一个在游戏里恶心过我的人都记了下来——**见一个，记一个，下次匹配见到，绕道走。**

一个私人维护的《穿越火线》玩家避雷名单：把游戏里遇到的捣乱玩家记进加密小本本，随时随地查、多设备同步，从此不被同一块石头绊倒两次。

**在线使用：https://yong-xu.github.io/cf-blacklist/**

---

## 为什么做这个

在游戏里遇到不喜欢的人是常有的事，但记不住、记不齐、记了又丢才是真正的麻烦：

- 靠脑子记？打个三五天就忘了谁是谁；
- 记在 Excel 里？每次翻找又慢又麻烦，手机上也看不了；
- 记在手机备忘录？改起来费劲，跟电脑还不互通。

这个页面把"记仇"这件事做成了顺手的事：**打开网页 → 输密码 → 记一笔 → 完事**。名单加密存到 GitHub 仓库，电脑、手机打开都是同一份，在哪记的都能同步。

## 功能

- **密码加密**：名单用 AES-256 加密后存进仓库，公开仓库也看不到明文内容
- **多设备同步**：任意设备上记一笔 / 删除 / 改密码，都会自动写回仓库，其他设备打开即同步
- **即输即搜**：按玩家名或关键词实时搜索，记过什么一眼看到
- **高危标记**：多次捣乱自动标"多次"，记了 3 次以上直接标"高危"，一眼识别惯犯
- **4 套主题**：简洁蓝 / 暗夜战术 / 极简白 / 赛博霓虹，一键切换，换着心情用
- **记住密码**：可勾选在本机记住密码，下次自动填好、点一下解锁就进（公共电脑千万别勾）
- **导出 / 导入**：加密备份 JSON、明文 CSV 都能导出，换设备、防丢失都靠它

## 快速开始

1. 打开 https://yong-xu.github.io/cf-blacklist/
2. 输入密码解锁（首次使用的初始密码见页面锁定屏提示，**进去后第一件事：修改密码**）
3. 右上角「记一笔」随手记下捣乱的人，点玩家可展开明细、删除记录

### 开启多设备同步（可选，推荐）

在「设置」里粘贴一个 GitHub **fine-grained PAT 令牌**（只给本仓库的 Contents 读写权限），之后所有更新都会自动写回仓库，换设备打开就是最新名单。令牌只存在你自己的浏览器里，不经过任何第三方。

## 安全说明

- 名单内容以 **AES-256-GCM 加密**（PBKDF2-SHA256 派生密钥）后存入公开仓库，**没有密码就解不开**
- 密码只存在你的脑子里（勾选"记住密码"后存在本机浏览器），请务必保管好，忘了密码谁都救不回来
- 仓库本身是公开的，**不要**把明文名单或密码提交进去
- 建议定期在「设置」里导出加密备份，双保险

## 技术实现

- 单文件 HTML + 原生 JavaScript，无框架、无构建，一个文件跑通全部
- Web Crypto API（PBKDF2-SHA256 + AES-256-GCM）加解密，纯浏览器端完成
- 数据存于 `data/encrypted.json`，读写走 GitHub Contents API（令牌写回 + SHA 冲突重试）
- 4 套主题基于 CSS 变量，一键切换并记住选择
